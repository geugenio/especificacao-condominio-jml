# Sobre o projeto
Este repositório foi desenvolvido para a disciplina de Lógica Aplicada À Engenharia de Software com foco em Especificação Formal com JML (Java Modeling Language).
-** Projeto base:** código original de domínio e interface foi obtido a partir do projeto acadêmico de https://github.com/eduardaperez/gerenciamento_condominio
- **Objetivo do trabalho:** Análise de integridade, identificação de inconsistências e especificação de contratos formais de software sobre o sistema existente.
